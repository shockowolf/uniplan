## Pitch Line

UniPlan은 소규모 기업이 ERP 데이터를 복잡한 메뉴 없이 자연어로 조회하고, 매출·미수·재고·상담 현황을 바로 분석할 수 있게 하는 AI 기반 경량 ERP입니다.

## Safety Line

UniPlan의 AI는 데이터를 마음대로 조작하는 AI가 아니라, 검증된 분석 템플릿을 통해 안전하게 ERP 데이터를 읽고 요약하는 AI 분석 레이어입니다.
