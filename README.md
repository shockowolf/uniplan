# Uniplan

Uniplan is a planning and data architecture workspace for the EASiSoft-related support/project proposal flow.

This repository contains the durable planning docs, architecture notes, data model, query templates, and handoff material needed to continue the project from Codex Cloud or a local Codex workspace.

## Start Here

1. `UNIPLAN_MVP.md`
2. `UNIPLAN_ARCHITECTURE.md`
3. `UNIPLAN_DATA_MODEL.md`
4. `UNIPLAN_QUERY_TEMPLATES.md`
5. `UNIPLAN_MOVE_BRIEF.md`

## Current Shape

- Documentation-first repository
- No app/runtime dependencies yet
- Intended to be managed through GitHub and Codex Cloud as `uniplan`

## Repository Rule

Do not commit personal credentials, local database dumps, private runtime state, or generated archive bundles.
